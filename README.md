Starting with a json string in the format that is given online, first I need to format it in such a way that json accepts which is getting rid of all asterisks and making them into quotations since 'BRO' is not recognizable to json but "BRO" is. Problems may arise if a teams name had an asterisk included in the name however the prompt says that actual values are unimportant. Next I deserialize the json into an embedded dictionary since dictionaries pair well with json and are fast. After all our data is in the dictionary then I format it so that all teams have a record against every other team including itself which in that case would be 0-0. To format the output data the column headers are fairly straightfoward with only needing a single loop. To output each row requires a nested loop where all the logic takes place. We iterate through the entire dictonary in both loops and if the team we are comparing to is itself then we just write in "---" for the H2H. If the team we are comparing to is a different team we search our dictionary for wins against the opposing team and output that in our matrix. We finish up by outputting the column names again but this time on the bottom.
